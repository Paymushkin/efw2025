# SEO: блок Designer Runways

## Проблема

Данные runway подгружаются с клиента из Google Sheets, поэтому «голый» клиентский рендер хуже индексируется.

## Решение

1. **Локальный снимок для SSR** — файл `constants/designerRunwaysData.ts` участвует в серверном/пререндеренном HTML, чтобы роботы видели контент.
2. **После загрузки страницы** данные при необходимости обновляются из Sheets (актуальность для пользователя).
3. **Обновление снимка вручную** — скрипт в репозитории (раньше это дублировал отдельный cron-workflow; **cron удалён**).

## Команды

```bash
npm run update-runways-data   # перезаписать constants/designerRunwaysData.ts из Google Sheets
npm run generate              # пересобрать статику после изменения констант
```

После изменения файла констант закоммитьте его и запушьте — сработает обычный деплой на GitHub Pages.

## Как это работает

1. **SSR / prerender** — в разметку попадают данные из `designerRunwaysData.ts`.
2. **Клиент** — `fetchRunways()` в composable подтягивает актуальный CSV при наличии сети.

## Настройка

- Таблица и преобразование строк задаются в `composables/useDesignerRunways.ts` и `scripts/updateDesignerRunwaysData.ts` (ID spreadsheet должен совпадать).
- Убедитесь, что экспорт CSV с листа доступен для запроса, который делает скрипт/браузер (права «Anyone with the link» / публичная таблица — по вашей политике).
